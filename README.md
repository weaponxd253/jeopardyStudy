# Jeopardy Study Game

## Try it here
https://weaponxd253.github.io/jeopardyStudy/

A simple web-based Jeopardy-style game designed for studying and reinforcing knowledge through an interactive quiz format.

## Features
- Interactive Jeopardy-style gameplay
- Customizable categories and questions
- Responsive design using HTML, CSS, and JavaScript


## Usage
- Click on a category and point value to reveal a question.
- Answer the question and track your score.
- Play solo or with multiple players.

## File Structure
- `index.html` - Main game structure.
- `style.css` - Styling for the game layout.
- `script.js` - Logic for game interactions.

## Future Enhancements
- Add a backend for saving scores and custom questions.
- Implement a timer for each question.
- Improve mobile responsiveness.
